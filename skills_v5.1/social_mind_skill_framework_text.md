# 社会心智 Skill Library v5 完整框架（56+20）

完整版本包含 56 个微观 skill + 20 个宏观 skill，共 76 个 skill。

## 总体原则

1. 微观 skill 对焦一个具体社会心智能力；允许相邻，但必须有不同核心变量。
2. 宏观 skill 对焦一个可直接路由的场景原型；它不是微观 skill 的简单拼接。
3. 微观层追求能力完备，宏观层追求高频场景原型完备。
4. 每个 skill 都需要明确：核心变量、适用问题、排除边界。
5. L0 是元控制层，承担路由、证据、解释竞争和反偏误检查；不再需要独立 `ROUTING.md`。

---

## 一、微观层：56 个原子能力

格式：`编号` 名称：能力说明。核心变量：该 skill 真正判断的变量。边界：与相邻 skill 的区别。

### L0 元认知与解释控制层：4 个微观 skill

- `micro-01` 任务路由：识别题目真正要求的心智变量。核心变量：问题要求输出的心理/社会变量。边界：不负责具体求解，只负责选择能力入口。
- `micro-02` 证据链构建：区分文本证据、推断与常识补全。核心变量：结论由哪些证据支持。边界：不比较多个解释，只整理证据来源。
- `micro-03` 多解释竞争：保留并比较多个可能解释。核心变量：哪个解释最能同时解释证据。边界：不做价值判断，只做解释选择。
- `micro-04` 反偏误检查：防止视角偏差、结果偏差、道德直觉抢答。核心变量：当前推理是否被非角色视角或直觉带偏。边界：不生成新解释，只检查已有解释。

### L1 感知、注意、记忆、知识层：6 个微观 skill

- `micro-05` 感知通道访问：谁看见、听见、摸到、闻到什么。核心变量：角色是否能通过感官接触信息。边界：不判断是否注意到，只判断是否可感知。
- `micro-06` 空间视角转换：从他人位置看到什么。核心变量：从目标视角可见的空间关系。边界：不判断信念，只判断视角可见性。
- `micro-07` 注意与显著性：谁注意到关键线索，谁忽略了。核心变量：信息是否进入角色注意焦点。边界：不同于感知访问；看见不等于注意到。
- `micro-08` 时间顺序与事件更新：先后顺序如何改变心理状态。核心变量：事件发生顺序及其更新效应。边界：不判断记忆保持，只判断事件序列。
- `micro-09` 记忆、遗忘与误记：知道、记得、忘记、记错。核心变量：角色当前记忆状态。边界：不同于知识边界；这里关注曾经接触后的保持或扭曲。
- `micro-10` 知识边界：专业知识、文化知识、生活经验、未知概念。核心变量：角色是否具备理解该信息所需背景知识。边界：不同于感知或记忆，关注背景能力是否存在。

### L2 信念与心智模型层：8 个微观 skill

- `micro-11` 一阶信念：X 认为事实是什么。核心变量：角色对事实的主观表征。边界：不要求该信念错误。
- `micro-12` 错误信念：X 的信念与现实不一致。核心变量：信念和现实之间的偏差。边界：必须存在现实-信念冲突。
- `micro-13` 二阶/递归信念：X 认为 Y 认为什么。核心变量：一个心智模型嵌套另一个心智模型。边界：不同于共同知识，重点是递归归因。
- `micro-14` 外观-现实区分：看起来是什么，实际上是什么。核心变量：表象与真实状态的差异。边界：不必涉及某个角色的错误信念。
- `micro-15` 证据可得性更新：新证据如何改变信念。核心变量：新信息对信念的更新方向。边界：不同于来源可信度，重点是证据是否可得及其更新作用。
- `micro-16` 共同知识：双方是否都知道，且知道对方知道。核心变量：知识是否被双方公开共享。边界：不同于二阶信念，重点是共享性和公开性。
- `micro-17` 不确定信念：X 只是猜测、怀疑、半信半疑。核心变量：角色信念的确定度。边界：不同于来源可信度，关注主观置信水平。
- `micro-18` 来源可信度：传闻、目击、权威、谎言来源如何影响信念。核心变量：信息来源的可靠性。边界：不同于不确定信念，关注置信的原因。

### L3 欲望、目标、意图、行动层：7 个微观 skill

- `micro-19` 自我偏好：角色自己喜欢或想要什么。核心变量：角色自身偏好。边界：不判断其是否理解别人偏好。
- `micro-20` 他人偏好：角色理解别人喜欢或想要什么。核心变量：角色对他人偏好的表征。边界：不同于自我偏好，关注对别人欲望的建模。
- `micro-21` 目标层级：长期目标、短期目标、局部目标。核心变量：目标之间的层级关系。边界：不处理目标冲突时的选择。
- `micro-22` 意图识别：动作、眼神、手势背后的目的。核心变量：行为背后的即时目的。边界：不同于行动预测，关注当前动作为何发生。
- `micro-23` 行动预测：基于信念和目标预测下一步行为。核心变量：角色接下来最可能做什么。边界：不同于意图识别，关注未来行为。
- `micro-24` 承诺优先级：已有承诺、正在做的事、新邀请谁优先。核心变量：承诺或计划的优先顺序。边界：不同于一般目标冲突，必须有承诺/计划约束。
- `micro-25` 目标冲突仲裁：多个目标冲突时如何取舍。核心变量：冲突目标的权衡规则。边界：不要求已有承诺，适用于一般目标竞争。

### L4 情绪与评价层：8 个微观 skill

- `micro-26` 基本情绪评价：成功、失败、威胁、损失、获得。核心变量：事件对角色目标/利益的评价。边界：不处理伪装、反事实或道德情绪。
- `micro-27` 非典型情绪：为何出现反常或出乎意料的情绪。核心变量：情绪与常规预期的偏离原因。边界：不等于隐藏情绪，真实感受本身就是反常的。
- `micro-28` 隐藏情绪：真实感受与表面表现不一致。核心变量：真实情绪和外显表现的差异。边界：不解释隐藏规则，只识别内外不一致。
- `micro-29` 情绪伪装与展示规则：为了礼貌、身份、场合隐藏情绪。核心变量：为什么以及如何管理外显情绪。边界：不同于隐藏情绪，重点是社会规则导致的表达控制。
- `micro-30` 道德情绪：内疚、羞耻、骄傲、愤怒、感激。核心变量：责任、规范或价值评价引发的情绪。边界：不同于基本情绪，必须含道德/规范评价。
- `micro-31` 反事实情绪：后悔、庆幸、失望、惊喜。核心变量：现实和可能替代结果的比较。边界：不处理单纯成功/失败情绪。
- `micro-32` 共情与情绪感染：他人情绪如何影响自己。核心变量：他人情绪对自我情绪的传递。边界：不同于理解他人情绪，重点是自身被影响。
- `micro-33` 情绪调节：压抑、转移、合理化、自我安慰。核心变量：角色如何改变或管理自己的情绪状态。边界：不同于展示规则，关注内在调节而非外显礼貌。

### L5 语言、语用与交流层：8 个微观 skill

- `micro-34` 字面意义理解：话语表面说了什么。核心变量：句子显式语义。边界：不推断隐含意图。
- `micro-35` 间接言语行为：暗示、请求、拒绝、提醒、警告。核心变量：话语执行的社会动作。边界：不同于会话含义，关注“这句话在做什么”。
- `micro-36` 会话含义：没明说但按语境可推出的意思。核心变量：语境推出的隐含信息。边界：不同于间接言语行为，关注“额外传达了什么”。
- `micro-37` 真话、谎话、半真话：陈述与事实的关系。核心变量：话语内容的真值状态。边界：不判断是否有意误导。
- `micro-38` 误导与选择性表达：说真话但让人形成错误理解。核心变量：表达是否诱导错误推断。边界：不同于谎言，内容可以是真的。
- `micro-39` 说话动机：礼貌、保护面子、试探、回避、讨好。核心变量：说话者为什么这样说。边界：不同于说服策略，不一定要改变对方态度。
- `micro-40` 受众校准：对专家、新手、儿童、外群体如何表达。核心变量：表达如何适配听者能力/身份/立场。边界：不同于说服，重点是适配而非影响。
- `micro-41` 说服策略：如何改变对方信念、态度或行为。核心变量：影响对方的策略。边界：不同于协商让步，主要是单向影响。

### L6 社会规范、关系与互动修复层：11 个微观 skill

- `micro-42` 失礼与冒犯：faux pas、尴尬、冒犯性话语。核心变量：行为是否违反社交得体性。边界：不判断责任归属或修复方案。
- `micro-43` 伤害与责任：谁造成伤害，是否有意，是否可责备。核心变量：伤害责任归属。边界：不同于失礼判断，重点是责任和可责备性。
- `micro-44` 公平与互惠：分配、公平、回报、占便宜。核心变量：资源/义务是否公平互惠。边界：不同于协商，关注规范评价而非达成方案。
- `micro-45` 信任与声誉：是否可靠，过往行为如何影响信任。核心变量：长期可靠性评估。边界：不同于来源可信度，关注人际历史而非单次信息来源。
- `micro-46` 权力、地位与角色：老师/学生、上司/下属、专家/新手。核心变量：互动双方的角色结构。边界：不选择沟通策略，只识别结构。
- `micro-47` 群体身份：内群体、外群体、刻板印象、归属。核心变量：群体归属如何影响理解和评价。边界：不同于权力角色，关注身份边界。
- `micro-48` 隐私、秘密与边界：什么信息能说，什么不该说。核心变量：信息披露边界。边界：不处理已经越界后的修复。
- `micro-49` 关系修复与道歉：识别何时需要道歉、解释、补救或缓和关系。核心变量：关系损伤后的修复需求。边界：不同于失礼判断，关注后续修复动作。
- `micro-50` 自我呈现与印象管理：控制自我信息、形象、露出顺序与自我描述方式。核心变量：希望他人形成怎样的自我印象。边界：不同于情绪展示规则，关注整体形象管理。
- `micro-51` 协商让步与共同方案：在分歧中寻找折中、交换条件、共同可接受方案。核心变量：双方如何通过让步形成共同方案。边界：不同于说服，协商要求双向调整。
- `micro-52` 权力应对与层级沟通：识别上下级、越级、授权、服从、挑战与退让策略。核心变量：在权力差中选择怎样的沟通动作。边界：不同于权力角色识别，关注应对策略。

### L7 数量、概率与社会推断层：4 个微观 skill

- `micro-53` 模糊数量先验：一些、大多数、几乎没有、差不多一半。核心变量：模糊数量词对应的大致范围。边界：不处理观察后更新。
- `micro-54` 部分观察后的数量更新：观察样本后修正估计。核心变量：新样本如何改变数量估计。边界：不同于基率，关注样本证据更新。
- `micro-55` 基率与典型性：用常见性判断可能性。核心变量：背景概率或典型性。边界：不同于模糊数量，关注类别可能性。
- `micro-56` 因果归因：结果由谁、什么事件、什么条件导致。核心变量：结果的原因归属。边界：不同于责任判断；因果可以不含责备。

## 二、宏观层：20 个场景原型 skill

格式：`编号` 名称。场景核心变量：该宏观 skill 直接求解的场景问题。展开：需要诊断或解释时可调用的微观 skill。

- `macro-01` 经典错误信念判断  
  场景核心变量：角色会按错误信念去哪里找或做什么。  
  展开：`micro-05`, `micro-08`, `micro-11`, `micro-12`, `micro-23`。
  边界：区别于二阶心智和外观-现实，本场景核心是角色依据错误信念行动。

- `macro-02` 二阶心智与共同知识  
  场景核心变量：一个角色如何理解另一个角色的理解。  
  展开：`micro-13`, `micro-16`, `micro-17`, `micro-18`。
  边界：区别于一阶错误信念，本场景核心是心智嵌套或共同知识。

- `macro-03` 外观-现实与知识边界  
  场景核心变量：表象、真实与角色知识边界如何共同决定回答。  
  展开：`micro-10`, `micro-14`, `micro-15`, `micro-18`。
  边界：区别于错误信念行动预测，本场景核心是表象、真实与知识边界的冲突。

- `macro-04` 社会线索与非语言意图  
  场景核心变量：非语言线索传达了什么意图或社交动作。  
  展开：`micro-07`, `micro-22`, `micro-23`, `micro-26`, `micro-35`。
  边界：区别于语言语用，本场景核心是非语言线索的意图解释。

- `macro-05` 隐藏情绪与反常情绪  
  场景核心变量：角色真实感受为何不同于表面或常规预期。  
  展开：`micro-21`, `micro-26`, `micro-27`, `micro-28`, `micro-29`, `micro-31`。
  边界：区别于道德情绪，本场景核心是真实情绪与表面或常规预期不一致。

- `macro-06` 道德情绪与责任判断  
  场景核心变量：责任、伤害与规范评价引发什么情绪或判断。  
  展开：`micro-04`, `micro-30`, `micro-33`, `micro-43`, `micro-56`。
  边界：区别于一般情绪判断，本场景核心是责任、伤害和规范评价。

- `macro-07` 间接语言与会话含义  
  场景核心变量：说话者真正想让听者理解什么。  
  展开：`micro-34`, `micro-35`, `micro-36`, `micro-39`, `micro-48`。
  边界：区别于谎言误导，本场景核心是间接表达和会话含义。

- `macro-08` 谎言、半真话与误导  
  场景核心变量：话语如何在真值、动机和误导效果之间运作。  
  展开：`micro-18`, `micro-37`, `micro-38`, `micro-39`, `micro-45`。
  边界：区别于一般间接表达，本场景核心是真值、选择性表达和误导效果。

- `macro-09` 说服、建议与受众校准  
  场景核心变量：如何让表达适配听者并改变其信念、态度或行为。  
  展开：`micro-03`, `micro-20`, `micro-40`, `micro-41`, `micro-46`。
  边界：区别于双向协商，本场景核心是面向听者的表达适配和单向影响。

- `macro-10` 偏好冲突与共同决策  
  场景核心变量：多方偏好冲突时应选择什么行动或分配。  
  展开：`micro-19`, `micro-20`, `micro-21`, `micro-23`, `micro-25`, `micro-44`。
  边界：区别于协商过程，本场景核心是偏好冲突下的选择或分配判断。

- `macro-11` 承诺、计划与下一步行动  
  场景核心变量：已有承诺和新机会竞争时下一步行为是什么。  
  展开：`micro-08`, `micro-21`, `micro-23`, `micro-24`, `micro-25`。
  边界：区别于一般目标冲突，本场景核心是承诺、计划与下一步行动。

- `macro-12` 失礼、冒犯与社会尴尬  
  场景核心变量：行为是否造成社交冒犯、尴尬或面子威胁。  
  展开：`micro-30`, `micro-39`, `micro-42`, `micro-46`, `micro-48`。
  边界：区别于道歉补救，本场景核心是是否造成冒犯、尴尬或面子威胁。

- `macro-13` 空间社会视角判断  
  场景核心变量：从目标角色视角能看到什么或会如何理解空间关系。  
  展开：`micro-05`, `micro-06`, `micro-07`, `micro-11`。
  边界：区别于信念推断，本场景核心是空间视角和可见性。

- `macro-14` 数量、概率与社会估计  
  场景核心变量：在模糊数量、样本和基率下如何估计。  
  展开：`micro-03`, `micro-53`, `micro-54`, `micro-55`。
  边界：区别于因果归因，本场景核心是数量、概率和估计。

- `macro-15` 信任、关系与长期互动  
  场景核心变量：长期历史如何影响信任、声誉和关系判断。  
  展开：`micro-18`, `micro-44`, `micro-45`, `micro-46`, `micro-47`, `micro-56`。
  边界：区别于单次来源可信度，本场景核心是长期关系历史和声誉。

- `macro-16` 对话误解修复与澄清  
  场景核心变量：实时对话中如何发现误解并澄清。  
  展开：`micro-02`, `micro-03`, `micro-36`, `micro-40`, `micro-48`。  
  边界：区别于关系损伤后的道歉补救，本场景关注实时误解澄清。

- `macro-17` 道歉、补救与关系和解  
  场景核心变量：关系受损后如何承认、补救并恢复互动。  
  展开：`micro-02`, `micro-42`, `micro-43`, `micro-48`, `micro-49`。  
  边界：区别于实时误解澄清，本场景关注关系损伤后的补救。

- `macro-18` 协商、折中与共同方案  
  场景核心变量：冲突双方如何通过让步达成共同可接受方案。  
  展开：`micro-19`, `micro-20`, `micro-25`, `micro-44`, `micro-51`。
  边界：区别于单向说服，本场景要求双方调整。

- `macro-19` 第一印象、自我呈现与正式互动  
  场景核心变量：如何管理自己呈现给他人的形象。  
  展开：`micro-29`, `micro-39`, `micro-40`, `micro-50`。

## 三、完整性与效率判断

### 微观层

56 个微观 skill 覆盖了社会心智的主要能力面：元控制、感知注意、信念建模、目标行动、情绪评价、语用交流、社会规范关系、数量概率因果。当前版本的效率来自两点：每个 skill 都有核心变量；容易混淆的相邻 skill 都有边界说明。

### 宏观层

20 个宏观 skill 覆盖了 benchmark 典型题型和真实场景原型。

### 调用建议

1. 场景高度匹配某个宏观 skill 时，直接调用宏观 skill。
2. 只需判断单一能力变量时，直接调用对应微观 skill。
3. 宏观求解出现证据缺口、边界混淆或解释不足时，展开对应微观 skill。
4. L0 微观 skill 用于控制整体解题质量：任务路由、证据链、多解释竞争、反偏误检查。
