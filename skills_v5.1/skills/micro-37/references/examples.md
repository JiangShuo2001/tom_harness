# micro-37 Examples and Boundaries

## Decision Variable
truth status of explicit content

## Route Signal
Use this micro unit when the diagnostic target is the factual accuracy of what was explicitly said.

## Hard Boundary
- This unit judges content-fact fit, not moral blame for lying.
- This unit does not decide whether the speaker knew the statement was false.
- This unit does not decide whether the listener was deceived.
- This unit does not analyze implied meaning unless it affects the explicit proposition being evaluated.

## Shortcut To Avoid
- Do not label a statement false merely because it is unhelpful, evasive, or suspicious.
- Do not label a literally true statement a lie just because it omits an important fact.
- Do not use the speaker's facial expression, motive, or relationship history to change the truth value of the explicit words.

## Common Failure Modes
- Conflating factual falsity with intent to deceive.
- Treating implication as if it were explicitly stated.
- Ignoring qualifiers such as 'some,' 'all,' 'before,' 'after,' 'maybe,' or 'I think.'
- Collapsing mixed claims into a single true-or-false label without checking each component.
- Using the listener's mistaken conclusion as proof that the utterance itself was false.

## Minimal Pair
- Case: Alex says, 'I put the keys on the table,' but the keys are in his backpack. | Why: The explicit claim conflicts with the facts, so the target variable is the truth status of the utterance content.
- Case: Alex says, 'I saw the keys earlier,' which is true, while avoiding saying that he later moved them. | Why: The literal truth can be evaluated here, but the main misleading effect belongs to micro-38 if the question asks about deception by omission.

## Boundary Stress Test
- A speaker says something false but sincerely believes it; classify the content as false, but do not infer intentional lying.
- A speaker says something true in a way that causes a false belief; classify the content as true, then route the misleading inference elsewhere.
- A sentence contains one true clause and one false clause; mark it as a half-truth or mixed-content statement rather than forcing a simple true label.
- A vague statement such as 'I finished most of it' requires checking whether the scene supports the vague quantity before judging truth status.

## Generalization Note
The unit generalizes to reports, excuses, answers, descriptions, and denials whenever the key operation is comparing explicit asserted content with known facts.
