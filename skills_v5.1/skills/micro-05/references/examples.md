# micro-05 Examples and Boundaries

## Decision Variable
whether the character can directly perceive the information through a sensory channel

## Route Signal
Use this unit when the scene asks whether information was perceptually available through a sensory channel.

## Hard Boundary
- This unit does not judge awareness, interpretation, or memory.
- This unit does not solve viewpoint or belief questions.
- This unit only asks whether direct sensory contact was possible.

## Shortcut To Avoid
- Do not treat seeing as the same as noticing.
- Do not treat hearing a sound as understanding its meaning.
- Do not treat being told something as direct perceptual access to the fact itself.

## Common Failure Modes
- Confusing access with attention
- Confusing access with belief update
- Confusing sensory availability with spatial perspective
- Using this unit for inference from clues instead of direct perception

## Minimal Pair
- Case: A person can see the red mug on the table but is reading a phone and never looks up. | Why: The mug is perceptually available through vision even if it is not noticed.
- Case: A person is behind a closed door and cannot hear the conversation inside. | Why: The sound is not available through the hearing channel, so sensory access is blocked.

## Boundary Stress Test
- If the character could have seen it but was distracted, still count access as yes.
- If the character inferred it from a clue without directly perceiving it, count access as no.
- If a second person described the object, do not count that as direct access to the object itself.

## Generalization Note
This unit applies across all sensory modalities and all content types as long as the question is only about direct perceptual availability.
