# Self-Presentation and Impression Management

## Use When
- Use when the question is about what image the person wants others to form.
- Use when the key choice is how to present self-information, order disclosures, or describe oneself.
- Use when the main task is managing how one is seen, not whether the information is private or true.
- Use when the scene asks what to reveal first, what to emphasize, or how to frame identity for an audience.

## Do Not Use When
- Do not use when the main issue is whether information should remain private; use privacy and boundaries instead.
- Do not use when the main issue is apology, repair, or easing hurt after harm; use relationship repair instead.
- Do not use when the main issue is negotiation, compromise, or mutual adjustment; use joint plan skills instead.
- Do not use when the main issue is power, hierarchy, escalation, or deference across rank; use power navigation instead.
- Do not use when the question is about true emotion display versus concealment; that is emotional inference or display, not overall image management.

## Decision Variable
the desired impression others should form

## Trigger Checklist
- Is the answer about how the person wants to be seen?
- Is the key lever what to say first, omit, emphasize, or frame?
- Is the content about identity presentation rather than fact detection?
- Would changing the order or tone of self-disclosure change the social image?
- Is the issue broad self-image, not one protected secret or one apology?

## Workflow
- Identify the audience and the social goal of the presentation.
- Ask what impression the speaker wants to create or protect.
- Check whether the choice is about disclosure order, framing, or self-description.
- Ignore the factual truth question unless deception is the main issue.
- Choose the option that best fits the intended image.

## Special Case
**Image management with truthful disclosure**: Truthful statements can still be impression management if the question is about which facts to lead with, how to frame them, or which identity to signal.

Scene: A job candidate lists volunteer work before test scores in a self-introduction.
Question: Why did they choose that order?
Answer logic: The decision is driven by the image they want to project first, so this is self-presentation rather than privacy, repair, or lying.

## Boundary Exit Rule
- If the core question becomes whether information should be shared at all, exit to privacy and boundaries (micro-48).
- If the core question becomes how to respond after offense or damage, exit to repair and apology (micro-49).
- If the core question becomes what action best satisfies both sides, exit to negotiation or joint planning (micro-51).
- If the core question becomes what a superior or subordinate should say, exit to power navigation (micro-52).
- If the core question becomes what emotion is actually being felt or shown, exit to emotion inference (micro-28 / micro-29).
- If the scene is a full first-impression or formal-interaction prototype rather than a single self-presentation diagnostic, route up to macro-19 and use this micro only as expansion.
