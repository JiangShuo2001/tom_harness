# Base Rate and Typicality

## Use When
- Use when the question asks which outcome, category, trait, role, or behavior is more likely based on how common it is in the population or setting.
- Use when a description must be weighed against a base rate, stereotype-like typicality cue, or prior category frequency.
- Use when the key inference is about likelihood before any decisive direct evidence is available.
- Use when social judgment depends on whether someone is a typical member of a group, role, situation, or pattern.

## Do Not Use When
- Do not use when the task is to interpret a vague quantifier such as some, most, almost none, or about half; route to micro-53.
- Do not use when the answer depends mainly on revising a numerical estimate after observing a sample; route to micro-54.
- Do not use when the question asks what caused an outcome rather than what is more likely; route to micro-56.
- Do not use when the scene gives a character's belief, perception, or intention as the decisive variable; use the relevant belief, perception, or intention micro instead.
- Do not use when a direct fact in the story overrides the prior probability.

## Decision Variable
background probability or category typicality

## Trigger Checklist
- The question asks what is more likely, more probable, typical, expected, or common.
- The scene provides a base rate, population frequency, role frequency, or ordinary-world prevalence.
- The scene includes a vivid individual description that may tempt ignoring the base rate.
- No decisive direct observation settles the answer.
- The answer requires comparing prior likelihoods across categories or outcomes.

## Workflow
- Identify the candidate categories, outcomes, or interpretations being compared.
- Extract any stated base rates, population sizes, role frequencies, or typicality cues.
- Separate diagnostic evidence from merely vivid or stereotypical description.
- Give priority to strong base rates unless the individual evidence is clearly more diagnostic.
- If no numbers are provided, use ordinary contextual typicality cautiously and state the comparison qualitatively.
- Answer in likelihood terms, not certainty, unless the scene provides decisive evidence.

## Special Case
**Vivid description versus base rate**: When a vivid description fits a rare category but the base rate strongly favors a common category, do not choose the rare category unless the description is specifically diagnostic rather than merely representative.

Scene: At a conference there are 90 engineers and 10 poets. Alex is described as quiet, precise, and fond of notebooks.
Question: Is Alex more likely to be an engineer or a poet?
Answer logic: The quiet-notebook description may feel poet-like, but it is not decisive. The strong base rate makes engineer more likely unless additional diagnostic evidence points to poet.

## Boundary Exit Rule
- Exit to micro-53 if the core operation is mapping words like many, few, most, or about half onto an approximate quantity range.
- Exit to micro-54 if a sample observation, partial count, or newly seen subset is supposed to update an estimate.
- Exit to micro-56 if the question asks which event or person produced the result.
- Exit to a belief or knowledge micro if the issue is what a character thinks is likely, rather than what is objectively likely from base rates.
- Exit to a macro route if the probability judgment is only one component of a larger negotiation, trust, false-belief, or communication scene.
