# micro-08 Examples and Boundaries

## Decision Variable
the event sequence and its updating effect

## Route Signal
Use this micro unit when reversing the order of two or more events would change the character's current mental state or predicted action.

## Hard Boundary
- Temporal updating is not memory retention: it assumes the relevant update remains available unless forgetting is explicitly at issue.
- Temporal updating is not attention: it assumes an accessible update is processed unless noticing is explicitly contested.
- Temporal updating is not background knowledge: it does not decide whether the character understands a concept or domain.
- Temporal updating is not final belief modeling by itself: it only supplies the chronology-based update needed by a belief or action route.

## Shortcut To Avoid
- Do not answer from the latest fact known to the reader; answer from the latest fact available to the character before the target time.
- Do not let narrative mention order replace story event order; a flashback or late sentence may describe an earlier event.
- Do not assume an earlier instruction still controls if a later accessible correction occurred before action.

## Common Failure Modes
- Using the real final location instead of the character's last accessible update.
- Ignoring that a message, warning, or correction happened after the character already acted.
- Treating failure to notice as an event-order problem when the cue was present but attention is the issue.
- Treating forgetting as simple chronology when the story explicitly says the character forgot or misremembered.

## Minimal Pair
- Case: Sam hears that the package is at the front desk, then later receives a message that it was moved to the mailroom before he goes to pick it up. | Why: The answer depends on a later event updating an earlier mental state before the target action.
- Case: Sam was told last week that the package was at the front desk, but today he cannot remember where it is. | Why: This is a near miss: the key variable is memory retention, so route to memory rather than temporal order.

## Boundary Stress Test
- A correction is sent before the character acts, but the character does not read it: event order alone is insufficient; check sensory access or attention.
- A character acts, then receives the correction: the correction cannot update the action already taken.
- A story reveals late that an event occurred earlier: use actual event chronology, not sentence order.
- A character hears an update in technical language they cannot understand: exit to knowledge boundary.

## Generalization Note
This unit generalizes to any social-cognitive scene where mental state is computed by ordered updates: instructions, corrections, discoveries, warnings, schedule changes, moved objects, changing commitments, or new evidence.
