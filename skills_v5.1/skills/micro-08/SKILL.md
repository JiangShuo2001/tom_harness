# Temporal Order and Event Updating

## Use When
- Use when the answer depends on which event happened first, next, or last.
- Use when a character's mental state changes because they received, missed, or acted on information at a particular time.
- Use when the question asks whether a later event updates, cancels, confirms, or makes obsolete an earlier mental state.
- Use inside false-belief, commitment, or next-action scenes when the key diagnostic issue is the event sequence rather than the final belief content.

## Do Not Use When
- Do not use when the main issue is whether the character noticed a cue that was present; use attention and salience instead.
- Do not use when the main issue is whether the character remembers or forgets something after previously knowing it; use memory, forgetting, and misremembering instead.
- Do not use when the main issue is whether the character has background expertise or cultural knowledge; use knowledge boundary instead.
- Do not use when the main issue is what is visible from a spatial position; use spatial perspective transformation instead.
- Do not use to judge moral blame, emotion, intention, or truthfulness unless the only unresolved variable is event order.

## Decision Variable
the event sequence and its updating effect

## Trigger Checklist
- Does the scene contain at least two ordered events?
- Did one event change the information available to a character?
- Is the character's current mental state different depending on whether an update occurred before or after another event?
- Would reversing the order of events change the answer?
- Is the question about the current result of the sequence, not about long-term memory retention?

## Workflow
- List the relevant events in chronological order, including who was present or informed at each step.
- Mark the character's mental state before the first relevant event.
- Apply each event as an update only if it occurred before the target question time and was accessible to the character.
- Ignore events that happened after the target decision point, even if they are mentioned later in the story.
- State the character's current mental state or likely action as the result of the final applicable update.
- If the answer requires deciding whether the character noticed, remembered, or had background knowledge, exit to the appropriate neighboring unit.

## Special Case
**Later correction overrides earlier expectation**: When a character receives a later correction before acting, the later correction updates the earlier belief; when the correction occurs after acting, it does not affect that action.

Scene: Maya is told the meeting is in Room A. Before she leaves, her manager texts that it has moved to Room B. Maya reads the text and then walks to the meeting.
Question: Where will Maya go?
Answer logic: The Room A belief is updated before Maya acts. Because the correction happened and was accessible before the target action, the current event-updated state points to Room B.

## Boundary Exit Rule
- If the key uncertainty is whether the character visually or physically had access to the information, exit to sensory access or spatial perspective rather than using event order alone.
- If the key uncertainty is whether the character noticed a visible cue, exit to attention and salience.
- If the key uncertainty is whether the character still remembers a prior event, exit to memory, forgetting, and misremembering.
- If the key uncertainty is whether the character could understand the information because of expertise, culture, or concepts, exit to knowledge boundary.
- If chronological order is only background and the real question is belief content, emotion, intention, deception, or norm judgment, route to that more specific unit.
