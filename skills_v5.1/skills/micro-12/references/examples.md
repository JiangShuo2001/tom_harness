# micro-12 Examples and Boundaries

## Decision Variable
whether the character's belief mismatches the actual state

## Route Signal
Use when a scene asks for one person's incorrect belief about a changed or hidden state of affairs.

## Hard Boundary
- A false belief requires an explicit belief-reality conflict.
- Do not infer false belief from ignorance alone.
- Do not use for nested belief attribution.

## Shortcut To Avoid
- Do not answer from the real-world state alone without checking the character's mental state.
- Do not confuse lack of expertise or background knowledge with believing a false fact.
- Do not use appearance-reality unless a character's belief is actually being queried.

## Common Failure Modes
- Answering with reality instead of the character's belief.
- Using this when the question only asks what the character saw or knew.
- Treating vague uncertainty as false belief.
- Confusing first-order belief with second-order reasoning.

## Minimal Pair
- Case: A character leaves an object in one place, another person moves it, and the character is asked where it is. | Why: The target character holds an outdated belief that conflicts with reality.
- Case: A character is asked whether a statement is literally true after receiving no misleading update. | Why: This may be a truth judgment or knowledge check, not necessarily a false belief diagnosis.

## Boundary Stress Test
- If the character knows the current state, do not call it false belief.
- If the question only asks what the character would say without testing reality mismatch, do not force this unit.
- If a second person is modeling the first person's belief, route away.

## Generalization Note
This unit generalizes to any direct mismatch between one agent's subjective representation and the actual world state, including hidden moves, concealed changes, and mistaken updates.
