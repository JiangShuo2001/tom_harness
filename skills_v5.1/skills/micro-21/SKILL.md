# Goal Hierarchy

## Use When
- Use when the question asks whether a goal is long-term, short-term, or local relative to another goal.
- Use when you need to identify which stated goal is a means to a higher goal and which is the end goal.
- Use when the task is to map the hierarchy among goals without choosing between them.

## Do Not Use When
- Do not use when the question asks which goal will win, which desire is stronger, or what the character will choose.
- Do not use when the main issue is preference, intention, action prediction, or commitment priority.
- Do not use when the scene is about resolving conflict between goals rather than classifying their levels.

## Decision Variable
which goal is superordinate versus subordinate

## Trigger Checklist
- There are two or more goals, plans, or aims mentioned.
- The question asks for level, nesting, or means-end relation.
- One goal appears to support another goal or larger purpose.
- No direct choice between competing goals is required.

## Workflow
- List every stated goal, plan, or objective.
- Ask whether one goal serves another goal or stands as the final aim.
- Classify each goal as long-term, short-term, or local.
- Answer with the hierarchy only, not with the chosen action.

## Special Case
**Subgoal inside a plan**: If a small action is part of a larger plan, treat it as a local or short-term goal only when the question asks for level, not when it asks which action will happen next.

Scene: A student studies for a quiz so that she can pass the class.
Question: Which goal is higher-level?
Answer logic: Passing the class is the higher-level goal; studying for the quiz is the subordinate goal that serves it.

## Boundary Exit Rule
- Exit to micro-25 Goal-Conflict Arbitration if the question asks which goal wins or is weighted higher.
- Exit to micro-24 Commitment Priority if a binding promise, plan, or schedule sets the priority.
- Exit to micro-23 Action Prediction if the scene requires predicting the next action from goals.
- Exit to micro-22 Intention Recognition if the issue is inferring the immediate purpose behind a current behavior.
- Exit to micro-19 or micro-20 if the issue is mental-state reading of the character's own or another person's desire or preference.
