# Appearance-Reality and Knowledge Boundary

## Use When
- Use when an object, situation, person, label, container, or event looks like one thing but is actually another.
- Use when the answer depends on whether a character knows the hidden reality or only has access to the appearance.
- Use when world knowledge, prior experience, labels, disguises, deceptive packaging, or restricted information creates a boundary between what is true and what a character can know.
- Use when the main question is what something really is, what a character thinks it is, or what it means inside that character's information state.

## Do Not Use When
- Do not use when the main question is where a character will search after an unseen object transfer; route to macro-01 instead.
- Do not use when the main question is what one character thinks another character knows or believes; route to macro-02 unless the appearance-reality conflict remains the main driver.
- Do not use when the main evidence is a wink, glance, smile, gesture, or other nonverbal cue conveying intention; route to macro-04.
- Do not use when the central task is to infer a hidden or atypical emotion rather than to separate appearance, truth, and knowledge access; route to macro-05.
- Do not use when a single narrower micro skill can answer a non-scene diagnostic question without the appearance-reality prototype.

## Decision Variable
how appearance, reality, and a character's knowledge boundary jointly determine the answer

## Direct Route Rule
Route immediately when appearance conflicts with reality or world knowledge is fenced off.

## Trigger Checklist
- There is a visible or surface appearance that suggests one interpretation.
- There is a hidden or actual reality that differs from that appearance.
- At least one character has limited, partial, outdated, or privileged access to the reality.
- The question asks what the character thinks, says, identifies, expects, or understands rather than simply asking the objective truth.
- Solving requires keeping separate the narrator's knowledge, the object's real state, and the character's knowledge boundary.

## Workflow
- Identify the apparent state: what the item, event, label, container, disguise, or situation seems to be from the relevant character's perspective.
- Identify the real state: what is actually true according to the scene.
- Map knowledge access for each relevant character: who saw the reveal, who was told, who has background knowledge, and who only saw the surface appearance.
- Answer from the requested standpoint, not from omniscient knowledge: if the question asks what a character thinks, use only that character's accessible evidence.
- If the character lacks the reveal, preserve the appearance-based belief even if the reader knows it is false.
- If the character has the reveal or necessary background knowledge, let the reality override the misleading appearance.
- If the question asks for the objective fact, answer with the reality, then optionally contrast it with the character's belief.
- Check that the answer is about appearance, reality, and knowledge boundary rather than action prediction, nested belief, nonverbal intention, or emotion.

## Special Case
**Deceptive container or misleading label**: When a familiar container, label, costume, or outward form suggests a normal content but the actual content is different, characters who did not see the substitution should infer the normal content, while characters who saw the substitution should know the real content.

Scene: A candy box is on the table. Mia sees her brother remove the candy and put pencils inside. Later, Noah enters and only sees the closed candy box.
Question: What will Noah think is inside the box?
Answer logic: Noah only has access to the appearance and ordinary meaning of the candy box, not the hidden substitution. He will think candy is inside, even though the real content is pencils.

## Boundary Exit Rule
- Exit to macro-01 if the scene's main answer is a search or action location based on a first-order false belief after an unseen move.
- Exit to macro-02 if the main variable is one character's model of another character's belief, knowledge, or ignorance.
- Exit to macro-04 if the main inference comes from a nonverbal social cue rather than from appearance versus reality.
- Exit to macro-05 if the key mismatch is between outward emotional display and true feeling.
- Add micro-10 when the case requires basic appearance-reality separation.
- Add micro-14 when the case turns on a knowledge boundary or information being fenced off.
- Add micro-15 when world knowledge, object identity, labels, disguises, or category knowledge determines what a character can infer.
- Add micro-18 when shared versus private knowledge must be tracked to repair the answer.
