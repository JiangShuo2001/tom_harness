# Commitment Priority

## Use When
- Use when a scene asks which plan, obligation, appointment, task, or invitation should come first.
- Use when an existing commitment constrains what the character can reasonably do next.
- Use when the key question is how to rank obligations, not which goal is strongest in the abstract.

## Do Not Use When
- Do not use when there is no prior commitment, schedule, obligation, or plan constraint.
- Do not use when the main issue is general goal conflict without a commitment hierarchy.
- Do not use when the question is about predicting the next action from belief and goal.
- Do not use when the question is about inferring why someone acted, looked, or gestured.
- Do not use when the main issue is emotion, persuasion, or social norm violation.

## Decision Variable
the priority order among commitments or plans

## Trigger Checklist
- There are at least two competing items: commitment, task, invitation, appointment, or obligation.
- One item is already underway, promised, scheduled, or socially binding.
- The question is which item should be treated as higher priority.
- The answer depends on plan constraint, not on hidden belief or emotion.

## Workflow
- List the competing commitments or plans.
- Identify which ones are already fixed by promise, schedule, deadline, or active engagement.
- Rank the items by constraint strength and urgency.
- Choose the option that best preserves the highest-priority commitment.

## Special Case
**New invitation versus existing obligation**: When a new invitation conflicts with an existing promise or ongoing task, the existing commitment usually has priority unless the scene explicitly states a stronger override such as emergency, cancellation, or explicit permission to reschedule.

Scene: Maya promised to help Sam move at 3 p.m., but at 2:50 p.m. her friend invites her to lunch.
Question: What should Maya prioritize?
Answer logic: The promised help is the prior commitment, so it outranks the new invitation.

## Boundary Exit Rule
- Exit to micro-25 Goal-Conflict Arbitration if there is no binding commitment or schedule constraint.
- Exit to micro-23 Action Prediction if the question asks what the character will do next rather than which plan has priority.
- Exit to micro-22 Intention Recognition if the scene asks why the person is doing something.
- Exit to micro-21 Goal Hierarchy if the issue is classifying goals as long-term versus subordinate rather than ranking commitments.
- Exit to a persuasion or repair unit if the main issue is how to talk about the conflict, not which plan to honor.
