# micro-09 Examples and Boundaries

## Decision Variable
current memory content and fidelity

## Route Signal
Use this micro unit when a question asks what survives, fades, or changes in a character's memory after prior exposure.

## Hard Boundary
- Prior exposure must already be established or strongly implied.
- The answer must depend on memory retention, omission, or distortion.
- Do not use if the key uncertainty is perception, comprehension, or belief formation instead of recall.

## Shortcut To Avoid
- Do not infer memory loss just because the character gives a wrong answer; check whether the failure could instead be lack of attention or lack of knowledge.
- Do not treat every mistaken statement as a memory problem; some are beliefs, guesses, or lies.

## Common Failure Modes
- Confusing not seeing with forgetting.
- Confusing not understanding with misremembering.
- Confusing belief revision with memory distortion.
- Treating event order questions as memory questions even when recall is not being tested.

## Minimal Pair
- Case: The child heard the code yesterday and cannot repeat it today. | Why: The question is whether the previously heard item is still retained in memory.
- Case: The child was in the room but never looked at the code card. | Why: The failure is attention or access, not memory retention.

## Boundary Stress Test
- If the person never encoded the detail, this is not memory.
- If the person remembers the detail but interprets it with new background knowledge, check whether the question is really about belief or knowledge boundary.
- If the person says something false about a past event, ask whether it is a memory distortion or a deliberate lie.

## Generalization Note
This skill covers retention, forgetting, partial recall, and false recollection after exposure, but not perception, world knowledge, or current belief formation.
