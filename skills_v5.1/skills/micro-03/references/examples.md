# micro-03 Examples and Boundaries

## Decision Variable
which explanation best accounts for the available evidence

## Route Signal
Use when the question explicitly asks which explanation, interpretation, reading, or account best fits the evidence.

## Hard Boundary
- Not a value judgment skill.
- Not an evidence-tagging skill.
- Not a bias-correction skill.
- Not a belief-attribution skill.

## Shortcut To Avoid
- Do not pick the explanation that matches the most salient detail while ignoring the rest.
- Do not confuse the solver's confidence with explanatory quality.
- Do not collapse multiple plausible readings into the first obvious one.

## Common Failure Modes
- Choosing the most emotionally vivid explanation instead of the best-supported one.
- Answering with a belief or intention when the question asks for explanation comparison.
- Using outside world knowledge to override the stated clues.
- Treating ambiguity itself as proof of one interpretation.

## Minimal Pair
- Case: Two explanations fit the same action, and the question asks which best explains the clues. | Why: The unit compares competing interpretations and selects the one with the best evidence fit.
- Case: A question asks whether a person saw something, remembered it, or believes it happened. | Why: This is about perceptual access or belief state, not explanation competition.

## Boundary Stress Test
- If only one clue is given, can you still justify two distinct interpretations?
- If a moral reaction is removed, does the core question still ask which explanation fits best?
- If you must name a belief or desire instead of a story, this is the wrong unit.

## Generalization Note
This skill generalizes to any case where several interpretations remain viable and the task is to preserve, compare, and choose the best explanatory account.
