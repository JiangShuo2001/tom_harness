# Multiple-Explanation Competition

## Use When
- Use when the task asks you to compare more than one plausible explanation for the same evidence.
- Use when the answer depends on which interpretation best accounts for the observed facts, not on judging good or bad.

## Do Not Use When
- Do not use when the task is only to identify the social or mental variable the question is asking for.
- Do not use when the task is only to separate evidence from inference or to list what supports a conclusion.
- Do not use when the task is mainly checking for perspective bias, outcome bias, or a moral-intuition shortcut.
- Do not use when there is only one plausible interpretation and the question is about factual recall, belief attribution, or action prediction.

## Decision Variable
which explanation best accounts for the available evidence

## Trigger Checklist
- Are there two or more plausible explanations?
- Is the task asking which interpretation is best, most likely, or most supported?
- Does the question require holding multiple readings in mind before choosing one?
- Is the choice based on explanatory fit rather than moral judgment, confidence style, or direct observation?

## Workflow
- List the plausible explanations that remain open.
- Check each explanation against every available clue.
- Prefer the explanation that explains more clues with fewer assumptions.
- Reject explanations that require unsupported leaps or ignore key evidence.
- Return the best-fitting explanation, not the one that feels most familiar.

## Special Case
**Same evidence, different stories**: Use this skill when the scene provides one set of clues that could support multiple stories, and the task is to choose the strongest story rather than to judge the people involved.

Scene: A friend arrives late, looks tired, and gives a short answer. Possible explanations include being busy, being upset, or being sick.
Question: Which explanation best fits the evidence?
Answer logic: Compare how well each explanation accounts for lateness, tiredness, and brevity together. Choose the explanation that covers the most clues with the fewest extra assumptions.

## Boundary Exit Rule
- Exit if the task shifts from choosing among explanations to identifying what evidence exists or where it came from.
- Exit if the task becomes a bias check, moral evaluation, or blame assignment.
- Exit if the question asks for a mental-state fact such as belief, desire, or intention rather than an explanation ranking.
- Exit if the scene is really about one person's perspective, not competing interpretations.
