# macro-01 Examples and Boundaries

## Decision Variable
where or how a character will act based on a false belief

## Route Signal
A character will search or act according to an outdated belief because a relevant change happened outside their awareness.

## Hard Boundary
- Current reality alone is not the answer when the question asks what the character will do.
- The macro requires first-order belief by the target character, not nested belief about another mind.
- If the target character received reliable updating evidence, the belief is no longer false and the classic false-belief route should not be used.
- If no action or belief-guided behavior is asked, this may be a knowledge, appearance-reality, or factual-recall problem instead.

## Shortcut To Avoid
- Do not answer with the real current location just because the narrator reveals it.
- Do not assume a character knows a change simply because the reader knows it.
- Do not upgrade a character's belief unless the scene gives that character perceptual or communicative access.
- Do not treat every hidden-object scene as false belief; the key is the target character's outdated belief.

## Common Failure Modes
- Reality bias: choosing the actual current location instead of the character's believed location.
- Omniscience leak: giving the target character information only the reader or another character has.
- Nested-mind confusion: answering what another observer expects the target to do rather than what the target will do.
- Appearance-reality drift: focusing on what the object really is instead of where the character believes it is.
- Over-updating: treating ambiguous noise, coincidence, or irrelevant evidence as proof that the character learned the change.

## Minimal Pair
- Case: Sam puts a toy in a box, leaves, and the toy is moved to a basket while he is away. Asked where Sam will look. | Why: This is a first-order false-belief search problem after an unseen move; Sam will look in the box.
- Case: Sam puts a toy in a box, leaves, sees through the window that it is moved to a basket, then returns. Asked where Sam will look. | Why: This is a near miss: Sam observed the move, so his belief updates and the classic false-belief answer no longer applies.

## Boundary Stress Test
- If the character was physically absent but received a clear message about the move, do not preserve the old belief.
- If the character saw only someone approach the object but not move it, decide whether that evidence is enough to update belief; if uncertain, add a perception or evidence-update micro unit.
- If the question asks where another person thinks the target will search, route to second-order belief.
- If the question asks what the container really holds despite misleading labeling, route to appearance-reality unless an action from a false belief is also asked.

## Generalization Note
This macro generalizes beyond toy-location benchmarks to any scene where action follows an outdated mental model: searching an old folder path, going to a previous meeting room, contacting an old phone number, using an unchanged plan after a silent schedule change, or expecting someone at a location they no longer occupy.
