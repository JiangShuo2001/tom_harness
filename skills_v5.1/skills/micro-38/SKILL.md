# Misleading and Selective Expression

## Use When
- Use when the question is whether a true expression causes the listener to draw the wrong conclusion.
- Use when the key issue is selective disclosure, framing, or emphasis that makes the audience infer something false.
- Use when the stated content may be accurate but the communicative effect is deceptive.

## Do Not Use When
- Do not use when the question is simply whether the utterance is true or false; use truth/lie judgment instead.
- Do not use when the main task is to infer an unstated conversational implication; use implicature instead.
- Do not use when the main task is the speaker's motive for speaking that way; use speaker motivation instead.
- Do not use when the issue is adapting language to the audience rather than misleading them.

## Decision Variable
whether the expression leads the listener to a false inference

## Trigger Checklist
- The literal statement can be true.
- The listener is likely to infer more than the sentence strictly states.
- The wrong answer depends on whether the audience is misled, not on factual truth alone.
- A hidden omission, framing choice, or partial disclosure changes the listener's belief.

## Workflow
- Check whether the utterance content is itself true.
- Check what inference a reasonable listener would make from the wording and context.
- Compare that inferred meaning with the actual situation.
- If the listener is pushed toward a false belief, classify it here; otherwise exit to truth, implicature, or motive.

## Special Case
**True but strategically incomplete**: A statement still belongs here if it is factually correct yet leaves out the key detail that would prevent a false belief.

Scene: A says, 'The apartment is in a great neighborhood,' but leaves out that it is next to a noisy nightclub.
Question: Is A misleading the listener?
Answer logic: Yes. The sentence may be true, but the selective omission steers the listener toward an overly positive and false impression.

## Boundary Exit Rule
- Exit to micro-37 Truth, Lie, and Half-Truth if the task asks whether the words are factually true or false rather than whether the listener is misled.
- Exit to micro-36 Conversational Implicature if the task asks what extra meaning was conveyed beyond the words without the inference being false.
- Exit to micro-39 Speaker Motivation if the task asks why the speaker chose that wording rather than whether it misleads.
- Exit to micro-40 Audience Calibration if the main issue is adapting the message to the listener's level rather than producing a false impression.
