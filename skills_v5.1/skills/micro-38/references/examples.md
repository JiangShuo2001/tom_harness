# micro-38 Examples and Boundaries

## Decision Variable
Does the expression lead the listener to a false inference?

## Route Signal
Route here when a true statement, partial statement, or framing choice is judged by whether it misleads the listener into a false belief.

## Hard Boundary
- Not about factual truth status.
- Not about indirect meaning that is deliberately conveyed as an extra message.
- Not about speaker motive unless motive is irrelevant and the question is only about misleading effect.

## Shortcut To Avoid
- Do not assume 'true sentence' means 'not misleading'.
- Do not over-focus on what was said; check what a normal listener would infer.
- Do not collapse selective omission into simple lying.

## Common Failure Modes
- Answering truth/lie instead of misleading effect.
- Treating any hidden meaning as implicature even when the target is false inference.
- Ignoring omitted context that changes the listener's belief.
- Blaming intent when the unit only asks about communicative effect.

## Minimal Pair
- Case: A says, 'I was with a doctor last night,' while the doctor was actually a veterinarian; the listener assumes a medical doctor. | Why: The wording is true in one sense but drives a wrong inference in the listener.
- Case: A says, 'The report is finished,' but the appendix is still missing and the listener thinks the full package is complete. | Why: The statement can be factually true in a limited sense while still misleading through omission.

## Boundary Stress Test
- If the sentence is true and the listener still would not reasonably infer anything false, do not use this unit.
- If the question is 'Did the speaker lie?', route away unless the task explicitly asks about misleading effect.
- If the wrong answer depends on hidden context rather than the expression itself, check whether the issue is implicature or motivation instead.

## Generalization Note
This unit covers deceptive framing, selective disclosure, and truth-preserving misleading communication across social, professional, and everyday contexts.
