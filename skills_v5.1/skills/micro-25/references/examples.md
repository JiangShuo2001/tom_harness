# micro-25 Examples and Boundaries

## Decision Variable
which goal gets greater weight in the character's prioritization rule

## Route Signal
Use this micro unit when the answer depends on how a character compares competing goals, not on a fixed commitment or a predicted next move.

## Hard Boundary
- No prior commitment means no commitment-priority logic.
- No single next action question means do not route to action prediction.
- No emotion question means do not route to appraisal.
- No social-meaning or persuasion question means do not route to pragmatics.

## Shortcut To Avoid
- Do not infer the most visible action and treat it as the whole goal structure.
- Do not assume a schedule or obligation unless the scene explicitly gives one.
- Do not convert a motivation question into an emotion question.

## Common Failure Modes
- Confusing goal weighting with next-step prediction.
- Using commitment priority when the scene only shows general desire conflict.
- Reading emotion as if it were the main cause of the choice.
- Answering with personality labels instead of the active weighting rule.

## Minimal Pair
- Case: A character wants to study and also wants to go to a party, with no deadline or promise involved. | Why: This is direct competition between goals, so the task is to infer which goal gets more weight.
- Case: A character promised to help a friend but now also wants to rest. | Why: This looks similar, but the promise introduces commitment priority, which is outside this unit.

## Boundary Stress Test
- If removing the commitment would change the answer, this is not Goal-Conflict Arbitration.
- If the question can be answered by naming the next action alone, it belongs elsewhere.
- If the key clue is an emotion word rather than a goal tradeoff, leave this unit.

## Generalization Note
This unit covers general goal tradeoffs across everyday, moral, social, and self-protective motives, as long as no prior commitment resolves the choice.
