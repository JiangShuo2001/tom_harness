# SC-01 Reference

## Decision Variable

- The key variable is which sensory channels the perceiver actually
  has, and what conclusions they can draw from JUST that subset.

## Route Signal

- Use this skill when one perceiver in the story is explicitly
  described as missing a sensory channel and the question asks what
  they conclude.

## Hard Boundary

- If all perceivers have full senses, route to `skill16` for geometry
  or to the appropriate emotion / belief skill.
- If the boundary is world-knowledge fencing, route to `skill17`.
- If the task is observer-reaction interpretation of an ambiguous
  cue, route to `skill6`.

## Shortcut To Avoid

- Do not let the narrator's omniscient multi-modal description leak
  into a single-channel perceiver's mind.
- Do not assume "deaf" means "no perception of music"; it means
  visual / tactile reasoning about the setup.

## Common Failure Modes

- Picking an answer that requires the missing channel ("whale song"
  for a deaf observer).
- Failing to compute two perceivers' conclusions separately.
- Treating "behind glass" the same as "in the room".

## Minimal Pair

- Case A: a deaf student near a water-phone reasons visually about
  the setup, not about the sound.
- Case B: a blind student near the same instrument reasons about the
  sound, not the visual shape.

## Boundary Stress Test

- `What does the deaf student think the water-phone is?` → this
  skill.
- `What does Wu Di see when he stands opposite you at the table?` →
  `skill16`.
- `Tara has never seen birds. What is she imitating?` → `skill17`.

## Generalization Note

- The transferable core is per-channel knowledge subtraction: the
  perceiver only knows what their channels deliver; the narrator's
  description does not transfer.
