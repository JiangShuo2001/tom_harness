# AC-01 Reference

## Decision Variable

- The key variable is the listener's expertise level on the term:
  expert, peer enthusiast, or novice.

## Route Signal

- Use this skill when the question explicitly names the listener's
  expertise and asks how to mention a technical term to them.

## Hard Boundary

- If the task is general persuasion strategy unrelated to expertise,
  route to `skill13`.
- If the task is decoding hidden meaning of an indirect sentence,
  route to `skill12`.
- If no specific listener expertise is mentioned, do not use this
  skill.

## Shortcut To Avoid

- Do not pick the textbook-definition option for an expert audience.
- Do not assume "informative" is always best — to an expert, it is
  patronising.

## Common Failure Modes

- Defaulting to the dictionary-definition option as if it were always
  the safe choice.
- Forgetting to use shared vocabulary plus a personal scene for an
  expert.

## Minimal Pair

- Case A: speaking to an expert → use the term as shared vocabulary
  plus a personal scene.
- Case B: speaking to a novice → define the term, give context, then
  share experience.

## Boundary Stress Test

- `How should you mention role-playing to a senior DM?` → this skill,
  expert branch.
- `How should you explain the same concept to a friend who has never
  played?` → this skill, novice branch.

## Generalization Note

- The transferable core is audience-aware register selection: shared
  vocabulary + personal anchor for experts; define-then-share for
  novices.
