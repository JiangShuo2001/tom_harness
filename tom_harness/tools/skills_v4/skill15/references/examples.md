# SS-02 Reference

## Decision Variable

- The key variable is the speaker's motive for departing from plain
  factual reporting (or, for discrepant-intentions items, the specific
  mechanism the story's literal motive cue licenses).

## Route Signal

- Use this skill when the task asks why a nonliteral, selective,
  mistaken, polite, or self-protective statement was made — including
  "what is the possible intention behind X's behavior?".

## Hard Boundary

- If the task only asks whether the statement is true, route to
  `skill14`.
- If there is no statement motive to explain, do not use this skill.
- If the task is persuasion strategy, route to `skill13`; if indirect
  speech decoding, route to `skill12`.

## Shortcut To Avoid

- Do not label every mismatch as deliberate lying.
- Do not answer with hidden facts alone; explain why that wording was
  chosen.
- Do not pick the bland paraphrase option in discrepant-intentions
  items.

## Common Failure Modes

- Collapsing forgetting, confusion, politeness, and deception into a
  single `lie` category.
- Explaining what happened but not why the speaker chose that
  particular wording.
- Confusing truth judgment with motive explanation.
- Choosing the neutral "X has a conflict and doesn't tell" option when
  a more SPECIFIC mechanism option ("see the rival blamed") matches the
  story's literal motive cue.

## Minimal Pair

- Case A: the same mismatch can come from forgetting or confusion.
- Case B: the same mismatch can come from face-saving,
  self-protection, or conflict avoidance.
- Case C (Discrepant-Intentions): "knows X but has a grudge with their
  team" → choose the SPECIFIC strategic-gain option, not the neutral
  "doesn't tell" paraphrase.

## Boundary Stress Test

- `Why did she say that?` → this skill.
- `Was what she said true?` → `skill14`.
- `What is the possible intention behind X's behavior?` → this skill,
  literal-cue anchoring branch.

## Generalization Note

- The transferable core is action explanation in communicative
  behaviour: infer the speaker's local goal, pressure, or memory state
  that made this wording instrumentally useful.
